# Автосборка блога

## Как это работает

Вместо ручного создания HTML-файлов вы пишете посты в папку `_posts/`, а скрипт `build.py` сам генерирует:
- Отдельные страницы для каждого поста
- Главную страницу блога (`index.html`) с анонсами
- `sitemap.xml` со всеми URL
- `robots.txt`

## Структура

```
legal-blog/
├── _posts/                    <- сюда кладёте новые посты
│   ├── 2026-08-09-kak-vyselit-devushku.md
│   └── 2026-08-09-alimenty-na-rebenka.md
├── _template.html             <- шаблон страницы поста
├── build.py                   <- скрипт сборки
├── .github/workflows/build.yml <- автосборка на GitHub
├── index.html                 <- генерируется автоматически
├── sitemap.xml                <- генерируется автоматически
├── robots.txt                 <- генерируется автоматически
└── kak-vyselit-devushku.html  <- генерируется автоматически
```

## Как добавить новый пост

1. Создайте файл в `_posts/` с именем: `YYYY-MM-DD-slug.md`
   - `YYYY-MM-DD` - дата публикации
   - `slug` - короткое название латиницей (будет частью URL)
   - Пример: `2026-09-01-razdel-imuschestva-pri-razvode.md`

2. В начале файла напишите front matter:

```markdown
---
title: "Раздел имущества при разводе в 2026 году"
description: "Как делится квартира, машина и накопления при разводе. Пошаговая инструкция."
category: "семейное право"
date: "2026-09-01"
---

<p>Текст поста в HTML...</p>
<h2>Заголовок раздела</h2>
<p>Ещё текст...</p>
```

3. Запустите сборку:
```bash
python build.py
```

4. Закоммитьте и запушьте:
```bash
git add .
git commit -m "новый пост: раздел имущества"
git push
```

## Автоматическая сборка (GitHub Actions)

Если настроен GitHub Actions, то при пуше на GitHub скрипт запустится сам:
- Вы пушите `_posts/2026-09-01-...md`
- GitHub Actions запускает `build.py`
- Генерируются `index.html`, `sitemap.xml`, новые `.html` файлы
- Всё автоматически коммитится обратно

Важно: если используете GitHub Actions, не запускайте `build.py` локально перед пушем - иначе будет конфликт. Либо пушьте только `_posts/`, либо только готовые файлы.

## Что изменится в Яндексе

- Каждый пост будет иметь свой URL: `серко.рф/legal-blog/razdel-imuschestva.html`
- `sitemap.xml` будет содержать все URL с `<loc>`
- Яндекс проиндексирует каждую страницу отдельно
- Трафика из поиска станет в 3-5 раз больше
