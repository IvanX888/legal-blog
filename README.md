# Автосборка блога (сохранен ваш дизайн)

## Что изменилось

- Ваши посты теперь в папке `_posts/` — это исходники
- `build.py` генерирует отдельные HTML-страницы для каждого поста
- `index.html` — главная с анонсами (ваш дизайн сохранен)
- `sitemap.xml` — правильный, с реальными URL
- Ваш дизайн (темная тема, sticky bar, Metrika, анимации) — сохранен полностью

## Структура

```
legal-blog/
├── _posts/                           <- ваши тексты (исходники)
│   ├── 2026-08-09-kak-vyselit-devushku.md
│   └── 2026-08-09-alimenty-na-rebenka.md
├── _template.html                    <- шаблон отдельной страницы поста
├── _style.css                        <- ваш CSS (извлечен из оригинала)
├── build.py                          <- скрипт сборки
├── .github/workflows/build.yml       <- автосборка на GitHub
├── index.html                        <- главная (генерируется)
├── sitemap.xml                       <- sitemap (генерируется)
├── robots.txt                        <- robots (генерируется)
├── kak-vyselit-devushku.html         <- пост 1 (генерируется)
└── alimenty-na-rebenka.html          <- пост 2 (генерируется)
```

## Как добавить новый пост

1. Создайте файл `_posts/YYYY-MM-DD-slug.md`:
```markdown
---
title: "Заголовок поста"
description: "Описание для SEO"
category: "семейное право"
date: "2026-09-01"
---

<p>Текст поста в HTML...</p>
```

2. Запустите `python build.py` (или запушьте на GitHub — Actions сам соберет)

3. Готово! Новый пост появится на главной и получит свою страницу.
